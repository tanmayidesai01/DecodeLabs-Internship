# Data Analytics Project 01 – Data Cleaning using Python
Description - 
This project performs basic **data cleaning and validation using Python and Pandas** on an Excel dataset.
It:

* Reads the Excel dataset
* Displays sheets and the first 5 rows
* Checks dataset shape and missing values
* Converts the Date column into datetime format
* Handles missing CouponCode values
* Checks duplicate OrderIDs and duplicate rows
* Checks invalid dates and numeric column data types
* Saves the cleaned data as `cleaned_data.xlsx`

How to Run
 1. Install Pandas and OpenPyXL
pip install pandas openpyxl

2. Run the Python file
python Project__01.py


3. Output
After running the project, the cleaned dataset will be saved as:
cleaned_data.xlsx
